# Security Policy 🔒

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within SamuLibre:

1. **Do not create a public issue**.
2. Report the vulnerability privately via [GitHub Private Vulnerability Reporting](https://github.com/saghet/SamuLibre/security/advisories/new) or by emailing the core maintainers.
3. Include detailed steps to reproduce, affected versions, and proof of concept if available.

We take all security reports seriously and will acknowledge receipt within 48 hours.
