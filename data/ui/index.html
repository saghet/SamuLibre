Versión Oficial 2.1.13 (Arquitectura Modular Rust)

Software de Código Abierto para Windows y Android.

SamuLibre es un antivirus y EDR open-source desarrollado en Rust de alto rendimiento. Integra análisis heurístico con entropía Shannon, reglas YARA-X, protección contra ransomware mediante señuelos tripwire, túnel cifrado y gestión rigurosa de excepciones de seguridad con anclaje criptográfico SHA-256.
